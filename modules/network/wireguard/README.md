# WireGuard (nccloud/wireguard-operator)

Deploys the [nccloud/wireguard-operator](https://github.com/nccloud/wireguard-operator)
via Helm (chart `wireguard-operator`, pinned version) and creates a `Wireguard`
server plus one `WireguardPeer` CR per peer.

- Peers are assigned IPs from `10.8.0.0/24` and get full-tunnel config
  (`AllowedIPs = 0.0.0.0/0`) with their keys auto-generated by the operator.
- The server is exposed as a MetalLB `LoadBalancer` service (UDP 51820).
- `external_address` (e.g. `home.linuxguru.net`) is baked into every peer
  config as the `Endpoint`. Router must forward UDP 51820 -> the LoadBalancer IP.
- `dns`/`dns_search_domains` are pushed to clients, so away-from-home peers
  resolve internal names through the VPN.

## Retrieve a peer config

```sh
kubectl get secret wg-server-peer-configs -n wireguard-system \
  -o jsonpath='{.data.<peer-name>}' | base64 -d
```

Import the output into a WireGuard client (desktop/mobile app or
`wg-quick`).

## Managed resources

| Resource | Kind | Notes |
|---|---|---|
| `helm_release.wireguard_operator` | Helm release | chart `wireguard-operator` 0.3.0 (appVersion v2.11.0), installs CRDs |
| `kubectl_manifest.wireguard_server` | `Wireguard` | server CR, `wg-server`, LoadBalancer, MTU 1380 |
| `kubectl_manifest.wireguard_peers` | `WireguardPeer` | one per entry in `var.peers` |
